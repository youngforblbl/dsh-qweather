# qweather —— 和风天气工具

回答任何天气问题时，先用下面的工具取实时数据，再基于数据回答，不要凭空编造天气。

## 工具选择

- **qweather_weather**：查数据、回答问题。自动按 range/fields 调用和风天气对应接口。
- **qweather_card**：把天气画成对话内卡片（当前天气 + 固定未来 5 小时逐小时[气温/降水概率/风向风级] + 蓝色以上预警 + 空气质量/日月起落/生活指数 + 更新时间）。
  用户说「画出来 / 展示卡片 / 生成天气卡片」时用它，**直接调用本工具即可**——它自带实时 + 逐小时 + 预警数据，
  **不要**先调 qweather_weather 再调卡片，否则对话里会先出现一串工具调用行而不是卡片直接弹出。
  卡片渲染后**不要**再复述全部数据，围绕卡片要点作答。

## qweather_weather 参数

- `location`：可缺省（用设置里的默认位置）。支持城市/区县名、LocationID（如 101010100）、“经度,纬度”。
- `range`：`now`（实时）、`hours`（逐小时，1-240，默认 5）、`days`（逐日，1-10，默认 3）。
- `fields`：逗号分隔的信息类别——`condition` 天气现象、`temp` 气温、`humidity` 湿度、`wind` 风、
  `precipitation` 降水、`air` 空气质量、`warnings` 预警、`astro` 日出日落；`all` 全部；缺省 `summary`。
- 例：「上海明天热不热」→ `qweather_weather(location="上海", range="days", days=2, fields="temp,condition,precipitation")`。

## 位置与配置

- 找不到位置时换更精确的写法（“北京 海淀”优于“海淀”），或用 LocationID / 经纬度。
- 工具报「未配置 API KEY / 已关闭」时，提示用户去 设置 → 插件 → 和风天气 配置或打开总开关。
- 数据时间以工具结果里的「数据时间」为准，回答时注明。

## 口径

- 气温单位 ℃；降水概率为百分比；预警保留蓝色及以上（仅过滤未知级别）。
- 和风天气数据来源标注：数据来源：和风天气。
